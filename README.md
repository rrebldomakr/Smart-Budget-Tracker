# 💰 Smart Budget Tracker

A personal finance dashboard designed to track spending habits with a focus on **automated financial health alerts**. This project demonstrates the ability to handle numerical data, perform real-time calculations, and implement conditional UI rendering based on "Business Logic."

## 🚀 Key Features
- **Real-Time Financial Math:** Automatically updates Total Spent and Remaining Balance.
- **Spending Threshold Logic:** Monitors "Fun" spending; if it exceeds 30% or 50% of total expenses, the UI dynamically changes color to warn the user.
- **Client-Side Persistence:** Data is stored in `localStorage`, meaning your budget stays saved even if you close the browser.
- **Responsive Dark Mode:** A sleek, high-contrast interface built with CSS Grid and Flexbox.

## 🛠️ Tech Stack
- **JavaScript (ES6+):** Logic engine, array manipulation, and math functions.
- **CSS3:** Custom properties (Variables) for dynamic theme switching.
- **HTML5:** Semantic structure.

## 🧠 Why I Built This
This project was designed to move beyond simple lists and move into **Data-Driven Development**. It proves I can:
1. Manage complex state (Objects within Arrays).
2. Implement conditional logic that affects the user experience (UX).
3. Handle user input validation and data type conversion (Strings to Floats).
